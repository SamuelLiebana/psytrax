# Contributing to psytrax

Thanks for helping make psytrax easier to use and trust.

The detailed contribution guide lives in the documentation:

- `docs/source/community/contributing.md`
- `docs/source/community/support.md`
- `docs/source/community/roadmap.md`

In short, the most useful contributions improve installation, documentation,
examples, tests, model reliability, or support for real behavioural datasets.
For substantial new models or API changes, please open an issue first so the
scientific assumptions and maintenance cost can be discussed before code is
written.
